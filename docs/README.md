## 실행 방법

```bash
# 1. 백엔드 (필수)
cd backend
gradlew.bat bootRun
# 또는 IntelliJ에서 BackendApplication 실행

# 2. AI 서버 (선택 — 꺼져 있어도 상품 등록은 정상 동작)
cd ai-server
pip install -r requirements.txt
uvicorn main:app --port 8000

# 3. 프론트엔드
cd frontend
npm run dev
```

### 환경변수

| 이름 | 용도 | 기본값 |
|---|---|---|
| `DB_PASSWORD` | MySQL 비밀번호 | (필수) |
| `JWT_SECRET` | JWT 서명 키 (32바이트 이상) | 개발용 기본값 있음 |
| `AI_SERVER_URL` | AI 추론 서버 주소 | `http://localhost:8000` |
| `FILE_UPLOAD_DIR` | 이미지 저장 경로 | `./uploads` |

### 관리자 계정 만들기

회원가입은 항상 `USER`로만 생성됩니다.

```sql
UPDATE users SET role = 'ADMIN' WHERE email = 'admin@email.com';
```

⚠️ **바꾼 뒤 반드시 재로그인**해야 합니다. 역할이 JWT 토큰 안에 들어 있어서, 기존 토큰에는 여전히 `USER`가 적혀 있습니다. (01번 문서 참고)

## 아직 남은 것

정직하게 적어둡니다. 발표에서 물어보면 이대로 답하면 됩니다.

### 기능

- **비밀번호 재설정** — 화면만 있고 API가 없습니다 (명세에도 없음)
- **리프레시 토큰 재발급** — 토큰을 발급만 하고 `POST /auth/refresh`가 없어서 1시간 후 재로그인 필요
- **리뷰 작성·신고 UI** — `window.prompt()`로 처리했습니다. 모달로 바꾸면 좋습니다
- **우편번호 검색** — 다음 주소 API 미연동
- **AI 모델** — FastAPI 서버는 있지만 실제 모델 대신 해시 기반 스텁

### 기술 부채

- **동시 주문 경합** — 두 사람이 같은 순간 주문하면 둘 다 통과할 수 있습니다. `@Version`(낙관적 락) 필요
- **관리자 신고 목록 N+1** — 신고 건마다 COUNT 쿼리가 나갑니다. `GROUP BY`로 한 번에 세면 해결
- **검색 키워드 앞 와일드카드** — `LIKE '%키워드%'`는 인덱스를 못 탑니다. Full-Text Index 필요
- **`ddl-auto: update`** — 운영에서는 위험합니다. Flyway 같은 마이그레이션 도구로 전환 필요
- **테스트 코드 없음** — 단위 테스트가 하나도 없습니다

### 3단계 카테고리

현재 코드는 카테고리가 **2단계(대분류-소분류)** 라고 가정합니다. 3단계가 되면 손자 카테고리가 필터에 안 걸립니다. (07번 문서 7번 참고)

## 다음에 공부하면 좋을 것

문서를 다 읽고 나면 이 순서로 확장하는 걸 권합니다.

1. **테스트 코드** — `@SpringBootTest`, `@DataJpaTest`, Mockito. 오늘 만든 상태머신은 테스트하기 아주 좋은 대상입니다
2. **락과 동시성** — `@Version`, `@Lock`. 위 "동시 주문 경합" 문제를 직접 해결해 보세요
3. **QueryDSL** — Specification보다 타입 안전하고 읽기 쉬운 동적 쿼리
4. **Flyway** — `ddl-auto` 없이 스키마를 버전 관리
5. **Docker Compose** — MySQL + 백엔드 + AI 서버를 명령 한 줄로 실행

각각 오늘 만든 코드에 바로 적용해볼 수 있는 것들입니다.
